Collectors

Optional data sources that poll standard APIs (Unraid, UniFi, SNMP, iDRAC, Home Assistant power). Each starts off. Keys come from template variables on the container, never from a file; this page shows only whether each variable is set. Switching one on edits collectors.yaml through the config editor, so it is checked, versioned, and audited. Set a server's address and key variable there first. Test asks the source if the connection works and stores nothing.
