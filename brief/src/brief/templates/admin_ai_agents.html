Agent evaluation

Each agent is tested against past cases with known good outcomes, run in a scratch copy so nothing real is touched. The score (0 to 100) is 60% cases passed, 30% how much of what it wrote was cited, 10% steps used. Changing an agent's prompt, model, tools, limits, or chain runs its cases first; a change that scores more than five points lower is held until you accept it. Test runs use real model calls and count against the day's budget. Add your own cases in /config/brief/fixtures/agents/.
